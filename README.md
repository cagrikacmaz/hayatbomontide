# Hayat Bomonti’de

Mahall Bomonti İzmir ve Canopy by Hilton İzmir çevresinde gelişen şehir
deneyimini anlatan iki dilli, mobil öncelikli tanıtım sitesi.

## Yerel geliştirme

```bash
npm install
npm run dev
```

## Üretim

```bash
npm run build
```

Ana dal güncellendiğinde site GitHub Pages üzerinde otomatik olarak yayımlanır.
Görsel kaynakları için `ASSET_SOURCES.md` dosyasına bakın.
